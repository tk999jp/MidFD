# サポートと不具合報告
MidFD への不具合報告、改善提案、使用感のフィードバックは歓迎します。

報告は GitHub Issues からお願いします。

MidFD は個人開発のソフトウェアです。

不具合報告や機能要望をいただいても、必ず対応できるとは限りません。
また、対応時期や修正可否を保証することもできません。
内容およびこのサポート方針に同意できる場合のみご利用ください。

## 報告前に確認してほしいこと
不具合と思われる挙動があった場合は、可能な範囲で次を確認してください。

- 最新の公開版、または報告対象のバージョンで再現するか
- 利用モードが「実用安定版（推奨）」か「高度機能α版」か
- キー操作体系が「標準」か「FD互換」か
- 同じ操作をもう一度行って再現するか
- 特定のファイル、フォルダ、ネットワークドライブ、外部ツールに依存していないか

再現条件が分かるほど、確認しやすくなります。

## 報告時に含めてほしい情報
GitHub Issues で報告する場合は、可能な範囲で次の情報を添えてください。

- MidFD のバージョン
- 利用モード
  - 実用安定版（推奨）
  - 高度機能α版
- キー操作体系
  - 標準
  - FD互換
- OS
- 操作手順
- 期待した結果
- 実際に起きた結果
- エラーメッセージ
- スクリーンショット
- 再現するファイル種別やファイルサイズ
- 外部ツールや 7-Zip を使用している場合は、その設定状況

## 対応しやすい報告
次のような報告は、原因を確認しやすくなります。

- 操作手順が具体的に書かれている
- 毎回再現する条件が分かっている
- 期待した結果と実際の結果が分かれている
- エラーメッセージやスクリーンショットがある
- 利用モードとキー操作体系が書かれている
- 対象ファイルの種類やサイズが分かる

例:

```text
バージョン: MidFD 2026.05.xx Stable
利用モード: 実用安定版（推奨）
キー操作体系: 標準
OS: Windows 11

操作手順:
1. 画像ファイルを選択する
2. Enter で表示する
3. Esc で戻る

期待した結果:
Browser画面へ戻る

実際の結果:
Viewerが閉じず、ステータス欄にエラーが出た
```

## 対応が難しい場合

以下のような内容は、対応を見送る場合があります。

* 再現条件が分からない問題
* 特定のPC、ネットワーク、外部ツール環境に強く依存する問題
* 現在の設計方針と大きく異なる要望
* ファイル操作の安全性を下げる可能性がある変更
* 個別環境の運用サポートに近い内容
* 高度機能α版に含まれる実験的機能の仕様変更要望
* 大規模な機能追加や設計変更を前提とする要望

報告内容を確認しても、対応できない場合があります。
その場合でも、今後の参考情報として扱うことがあります。

## 高度機能α版について

高度機能α版には、開発中または検証中の高度機能が含まれます。

不具合報告は歓迎しますが、次の点に注意してください。

* 仕様が変更される可能性があります
* 機能が一時的に無効化される可能性があります
* 実用安定版（推奨）より不具合が起きやすい場合があります
* 報告を受けても、すぐに修正できない場合があります

安定した利用を優先する場合は、実用安定版（推奨）を使用してください。

## 要望について

改善提案や機能要望も歓迎します。

ただし、MidFD は「ちょうどよい中間機能」を目指すファイルマネージャです。
すべての要望を取り込むのではなく、通常利用での安全性、操作の分かりやすさ、保守しやすさを優先します。

特に次のような要望は、慎重に判断します。

* 操作体系を大きく変えるもの
* ファイル操作の安全性に影響するもの
* 設定や保存形式を複雑にするもの
* 特定環境だけに強く依存するもの
* 高度機能α版をさらに複雑化するもの

## セキュリティに関する報告

ファイル削除、外部ツール実行、意図しないファイル書き換えなど、安全性に関わる問題を見つけた場合は、通常の不具合よりも詳しい情報を添えて報告してください。

可能であれば、次の情報を含めてください。

* 問題が発生した操作
* 対象ファイルやフォルダの状態
* ReadOnlyタブや実用安定版で再現するか
* 外部ツールや 7-Zip が関係しているか
* 再現手順
* 実際に発生した影響

## 返信や対応について

Issue への返信や対応には時間がかかる場合があります。

また、次のような判断を行うことがあります。

| 判断       | 意味                |
| -------- | ----------------- |
| 確認中      | 内容を確認しています        |
| 追加情報待ち   | 再現条件や環境情報が不足しています |
| 対応予定     | 修正または改善を検討しています   |
| 対応見送り    | 現時点では対応しません       |
| 高度機能α版扱い | 実験的機能として扱います      |

対応見送りは、報告内容を否定するものではありません。
MidFD の設計方針や保守範囲に照らして判断します。
