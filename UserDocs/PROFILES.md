# 機能範囲・操作方式・配色

MidFDの初回／基本セットアップでは、次の5領域をまとめて確認できます。

1. 機能範囲
2. 操作方式
3. 表示
4. 配色
5. 外部アプリ

これらは互いに独立した設定です。機能範囲を変えても、操作方式や外部アプリのpathが自動的に失われることはありません。

## 表示

タブ表示は「縦型（推奨）」または「横型」から選べます。縦型では左側にcategory／tabを並べ、横型では上部にcategory／tabを表示します。初回セットアップでは縦型が選択され、基本セットアップを再表示すると現在の保存値が表示されます。

## 機能範囲

### 基本機能のみ

次の基本操作を利用します。

- ファイル・フォルダの閲覧
- コピー、移動、削除、名前変更
- Mark
- 標準のキー操作
- 内蔵Viewer

追加の自動復元、外部受け渡し、MidFD管理ゴミ箱などは有効にしません。

### 便利機能まで使う（推奨）

「基本機能のみ」に加えて、次を有効にします。

- 起動時に前回の状態を復元
- マウスジェスチャー
- Functionバーの詳細説明
- メディアファイルのEnter外部再生
- パスのパンくず表示

通常はこの範囲から開始することを推奨します。必要になった機能だけ後から追加できます。

### すべての機能を使う

「便利機能まで使う」に加えて、次を有効にします。

- MidFD管理ゴミ箱
- Drag ZIP
- Drag ZIPへの内容一覧manifest同梱
- clipboardのtextをfileとして貼り付け

これらは削除方法や外部受け渡しへ影響するため、画面上で注意対象として分けて表示します。

### 個別設定

機能範囲を選ぶと、各項目へ既定値が反映されます。その後、個別のcheckboxを変更できます。

現在値が3つの既知範囲のどれにも一致しない場合は「個別設定」と表示されます。機能が無効化されたわけではなく、利用者が個別に組み合わせた状態です。

## 操作方式

### MidFD標準

現代的なshortcutと、MidFD標準のFunctionバー配置を使用します。

### FD／WinFD互換

Fキー、Shift+F、数字キーの一部をFD／WinFD寄りにします。

> [!NOTE]
> FD／WinFD互換はキー配置と表示上の互換を目的としたものです。オリジナルFDとの完全互換ではありません。また、利用できる機能範囲そのものを制限する設定ではありません。

詳しい割り当ては [KEYBINDINGS.md](KEYBINDINGS.md) を参照してください。

## 操作方式と配色の連動

操作方式を実際に選び直した場合、次のbuilt-in配色へ一方向で連動します。

| 操作方式 | 連動する標準配色 |
|---|---|
| MidFD標準 | MidFD標準 |
| FD／WinFD互換 | WinFD互換 |

この連動には次の条件があります。

- セットアップ画面を開いただけでは、保存済み配色を変更しません。
- 操作方式を実際に変更した場合だけ標準配色へ連動します。
- 連動後も、配色comboから別のbuilt-in／user presetを自由に選べます。
- user presetの内容、登録名、custom色は削除・上書きしません。

## 外部アプリ

セットアップ画面から次を指定できます。

- 7-Zip
- 動画tool folder
- 外部editor

### 7-Zip

未設定時は既知の場所から自動探索します。通常の圧縮画面は設定で次から選択できます。

- 自動
- 7-Zip標準Dialog
- MidFD簡易Dialog

「自動」は `7zG.exe` の標準Dialogを優先し、利用できない場合にMidFD簡易Dialogへfallbackします。

### 動画tool folder

同じfolder内の次の実行fileを役割別に使用します。

- `ffmpeg.exe`: 動画静止画preview
- `ffprobe.exe`: 動画情報・再生時間
- `ffplay.exe`: 動画・音声の外部再生

`ffplay.exe` が見つからない場合はWindowsの関連付けで開きます。静止画previewには `ffmpeg.exe` が必要です。

### 外部editor

任意のeditorを指定できます。未設定時でも内蔵Viewerなどの基本操作は利用できます。

## 初回起動時と設定画面からの再表示

### 初回起動時

- 「MidFD 初回セットアップ」として表示します。
- ［MidFDを開始］で選択内容を保存して起動します。
- taskbar／Alt+Tabから確認できる独立した画面として表示します。

### 設定画面から再表示

- 「MidFD 基本セットアップ」として表示します。
- 設定画面の「起動・ログ」から開きます。
- ［設定画面へ反映］は外側の設定UIへ値を戻します。
- 永続保存は外側の設定画面で［適用］または［OK］を押した時点です。
- ［キャンセル］では外側UIと保存済み設定を変更しません。

## 後から個別に変更する場所

| 設定 | 主な場所 |
|---|---|
| 一覧表示・Viewer表示 | 表示 |
| 配色preset・custom色 | 配色 |
| Drag ZIP・MidFD管理ゴミ箱・clipboard貼り付け | 操作 |
| keybind・Functionバー・マウスジェスチャー | 入力割り当て |
| 7-Zip・動画tool・外部editor | 外部連携 |
| 前回状態復元・基本セットアップ再表示 | 起動・ログ |

初回セットアップは全設定を初期化する画面ではありません。主要な開始設定をまとめて見直すための画面です。
