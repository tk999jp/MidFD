# MidFD

MidFD は、FDライクな操作感を目指した Windows 向け軽量ファイラーです。

キーボードを主体とした軽快なファイル操作を重視し、
昔ながらのファイラー文化を意識しつつ、
現代の Windows 環境で扱いやすい構成を目指しています。

タブ、カテゴリ、マーク、QuickAccess、
アーカイブ操作（7-Zip / Windows 標準 fallback）、
外部ツール実行、Command Palette、入力割り当てなどを備え、
日常的なファイル操作を素早く行えることを目指しています。
また、コマンドプロンプト、PowerShell、Windows Terminal、WSL、Git Bash などをよく使う方が、
Explorer とコマンドラインの間で使える軽量な GUI 補助ツールとして使うことも想定しています。

ファイルを素早く見て、選び、整理し、必要に応じて shell や外部ツールへ渡す使い方を重視しています。

ただし、MidFD はオリジナルの FD との完全互換を目的としたものではありません。
FDライクな操作感を参考にしつつも、
タブ機能など、現在の利用環境に合わせた独自の機能差分を含みます。

詳しい利用上の注意、免責、操作説明については、
`UserDocs` を参照してください。


## ダウンロード

通常利用する場合は、最新版の実行用パッケージをダウンロードしてください。

- [MidFD-win-x64.zip](https://github.com/tk999jp/MidFD/releases/latest/download/MidFD-win-x64.zip)

展開後、`MidFD.exe` を実行してください。

> 注意:
> GitHub の `Code > Download ZIP` や `Source code (zip)` はソースコードです。
> 通常利用する場合は、上記の `MidFD-win-x64.zip` を使用してください。

> 実行には [.NET 8 Windows Desktop Runtime](https://dotnet.microsoft.com/ja-jp/download/dotnet/8.0) が必要です。
> 「.NET Desktop Runtime」の Windows x64 版をインストールしてください。

## 操作カスタマイズ

MidFD では、Browser画面の主要操作を設定画面からカスタマイズできます。

- キーバインドは Command 単位で変更、無効化、既定復帰できます。
- Functionバー（下部のボタン表示・クリック・Fキー割り当て）は、通常 / Shift / Ctrl / Alt の各レイヤーに個別のコマンドと表示名を割り当てできます。
- マウスジェスチャーは 1方向4種 + 2方向12種の合計16パターンを割り当てできます。
- Help メニューから Command 一覧を開き、割り当て対象の Command を確認できます。

> 注意:
> キーバインドカスタマイズの対象は Browser 画面です。
> ImageViewer、TextViewer、ArchiveContents、各種Dialogのキー操作は従来契約を維持します。

## 画像ビューアと貼り付け

- 画像ビューアでドラッグ範囲選択し、`Ctrl+C` で選択範囲のみをコピーできます。
- 画像ビューアで右90度回転、左90度回転、左右反転、上下反転を行えます。
- 画像情報ダイアログで、通常画像の基本情報に加えて VideoStill 時は動画メタ情報も確認できます。
- 画像、テキスト、ファイル貼り付けで新規作成されたファイルは `Ctrl+Z` で取り消せます。

> 注意:
> テキストクリップボードの `.txt` ファイル化は、誤作成防止のため既定では OFF です。
> 貼り付けで作成したファイルの Redo 再作成は対象外です。

## 外部ツール連携

7-Zip、ffmpeg、ffprobe、ffplay、PowerShell、Explorer、外部エディタ、登録済み外部ツールなどの起動処理を見直し、パス検証と安全な引数受け渡しを補強しています。

登録済み外部ツールには Alt+英数字 slot を設定できます。Alt 単体で launcher を表示し、一覧から選択して起動できます。

> 注意:
> 外部ツールには、信頼できる場所にある実行ファイルを設定してください。

## 初回セットアップ

MidFD は初回起動時に、「MidFD 初回セットアップ」画面を表示します。

この画面では、キー操作体系（操作プリセット）、動画ファイルの Enter 動作、外部連携パスの指定に加えて、「初期オプション」として主要な任意機能（高度な使い方）を一括または個別チェックで設定できます。

初回セットアップは、後から「設定」画面の「起動 / 復元」から再表示できます。
これは全設定の初期化ではなく、基本設定をもう一度見直すための画面です。

### 初期オプション / 高度な使い方
`Workspace Snapshot` などの一部の高度な管理導線や追加のファイル操作補助機能（`Drag ZIP` など）について、初回起動時にまとめて有効化または無効化を設定できます。
これらの項目は、後から設定画面の「操作」タブにある「高度な使い方 / 詳細オプション」セクションでいつでも個別に ON / OFF を切り替えることができます。

## キー操作体系
MidFD には、初期オプション（高度な使い方の有効/無効）の設定とは別にキー操作体系（操作プリセット）があります。

| 種類 | 内容 |
|---|---|
| 標準 | 現代的なショートカット中心の操作体系 |
| FD互換 | Fキー中心の操作体系 |

FD互換は、主にファンクションキー割り当てと FunctionBar 表示の違いです。
利用できる機能そのものを切り替えるものではありません。

## 最初に覚えるキー

| 操作 | キー | 説明 |
|---|---|---|
| 開く / 表示 | Enter | 選択項目を開く、または内蔵ビューアで表示します |
| 関連付けで開く | Z | OS の関連付けでファイルを開きます |
| コマンド実行 | X | 選択項目や現在フォルダを使ってコマンドを実行します |
| PowerShell を開く | H | 現在フォルダで PowerShell を開きます |
| コマンドプロンプトを開く | Shift+H | 現在フォルダでコマンドプロンプトを開きます |
| 再読込 | Ctrl+R | 現在ディレクトリを再読込します |
| フィルタ | Ctrl+F | 一覧を絞り込みます |
| コマンドパレット | Ctrl+Shift+P | 機能や外部ツールを検索して実行します |

詳しいキーバインドは [UserDocs/KEYBINDINGS.md](UserDocs/KEYBINDINGS.md) を参照してください。

## 基本的な使い方
MidFD の基本的な操作の流れは次のとおりです。

1. カーソルキーでファイルやフォルダを選択する
2. Enter で開く、または内蔵ビューアで表示する
3. 必要なファイルをマークする
4. コピー、移動、削除、リネームなどを実行する
5. よく使う場所は QuickAccess に登録する
6. 迷ったら Command Palette から機能を検索する

詳細な使い方は [UserDocs/USER_GUIDE.md](UserDocs/USER_GUIDE.md) を参照してください。

## バージョン表記

MidFD は、日付ベースのバージョン表記を使用します。

例:
* `v202x.xx.xx`
* `MidFD v202x.xx.xx`

アプリ内のバージョン情報では、リリースバージョンとビルド識別用のコミット情報を表示します。
不具合報告時は、GitHub Releases のバージョン名と、アプリのバージョン情報を併記してください。

これは、巨大なメジャーバージョン番号よりも、「どの時点の安定状態か」を分かりやすくするためです。
