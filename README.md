# MidFD

MidFD は、FDライクな操作感を目指した Windows 向け軽量ファイラーです。

キーボードを主体とした軽快なファイル操作を重視し、
昔ながらのファイラー文化を意識しつつ、
現代の Windows 環境で扱いやすい構成を目指しています。

タブ、カテゴリ、マーク、QuickAccess、
アーカイブ操作（7-Zip / Windows 標準 fallback）、
外部ツール実行などを備え、
日常的なファイル操作を素早く行えることを目指しています。
また、コマンドプロンプト、PowerShell、Windows Terminal、WSL、Git Bash などをよく使う方が、
Explorer とコマンドラインの間で使える軽量な GUI 補助ツールとして使うことも想定しています。

ファイルを素早く見て、選び、整理し、必要に応じて shell や外部ツールへ渡す使い方を重視しています。

ただし、MidFD はオリジナルの FD との完全互換を目的としたものではありません。
FDライクな操作感を参考にしつつも、
タブ機能など、現在の利用環境に合わせた独自の機能差分を含みます。

詳しい利用上の注意、免責、操作説明については、
`UserDocs` を参照してください。


## ダウンロード

通常利用する場合は、最新版の実行用パッケージをダウンロードしてください。

- [MidFD-win-x64.zip](https://github.com/tk999jp/MidFD/releases/latest/download/MidFD-win-x64.zip)

展開後、`MidFD.exe` を実行してください。

> 注意:
> GitHub の `Code > Download ZIP` や `Source code (zip)` はソースコードです。
> 通常利用する場合は、上記の `MidFD-win-x64.zip` を使用してください。

> 実行には .NET 8 Windows Desktop Runtime が必要です。

## 主な特徴
- キーボード中心のファイル操作
- タブとカテゴリによる作業場所の整理
- Alt+F2 / メニューからの Explorer 起動導線
- MarkSlot によるマーク状態の保存・復元
- QuickAccess によるよく使う場所への移動
- 一覧表示モード（ファイル名のみ / サイズ / サイズ+更新日時）
- アンダーラインカーソル表示
- 配色タブ（表示色プリセット、ユーザープリセット、HEX/RGB編集）
- Logdsk / Move 先履歴（Up/Down=履歴, Tab=補完）
- マウスジェスチャー（Browserの戻る/進む）
- アーカイブ操作 (7-Zip 連携および Windows 標準 fallback)
- 外部ツールの登録・実行
- Command Palette による機能検索
- 基本プレビュー / 画像プレビュー / 動画静止画プレビュー（ffmpeg / ffplay / ffprobe 任意連携）
- 実用安定版と高度機能α版の切り替え

## 初回セットアップ

MidFD は初回起動時に、「MidFD 初回セットアップ」画面を表示します。

この画面では、利用モードに加えて、キー操作体系、動画ファイルの Enter 動作、外部連携を設定できます。

初回セットアップは、後から「設定」画面の「起動 / 復元」から再表示できます。
これは全設定の初期化ではなく、基本設定をもう一度見直すための画面です。

### 実用安定版（推奨）
通常利用向けの安定モードです。

基本ファイラ機能、タブ、カテゴリ、QuickAccess、MarkSlot 基本機能、アーカイブ操作 (7-Zip / Windows標準 fallback)、外部ツール基本実行などを有効にします。
**通常はこちらを推奨します。**

### 高度機能α版
開発中の高度機能を含むモードです。
Workspace Snapshot、MarkSlot 集合演算、画像減色などの画像処理系機能、高度な自動追従など、検証中の機能が含まれる場合があります。
不具合や仕様変更の可能性があるため、安定利用を優先する場合は「**実用安定版（推奨）**」を使用してください。

## キー操作体系
MidFD には、利用モードとは別にキー操作体系があります。

| 種類 | 内容 |
|---|---|
| 標準 | 現代的なショートカット中心の操作体系 |
| FD互換 | Fキー中心の操作体系 |

FD互換は、主にファンクションキー割り当てと FunctionBar 表示の違いです。
利用できる機能そのものを切り替えるものではありません。

## 最初に覚えるキー

| 操作 | キー | 説明 |
|---|---|---|
| 開く / 表示 | Enter | 選択項目を開く、または内蔵ビューアで表示します |
| 関連付けで開く | Z | OS の関連付けでファイルを開きます |
| コマンド実行 | X | 選択項目や現在フォルダを使ってコマンドを実行します |
| PowerShell を開く | H | 現在フォルダで PowerShell を開きます |
| コマンドプロンプトを開く | Shift+H | 現在フォルダでコマンドプロンプトを開きます |
| 再読込 | Ctrl+R | 現在ディレクトリを再読込します |
| フィルタ | Ctrl+F | 一覧を絞り込みます |
| コマンドパレット | Ctrl+Shift+P | 機能や外部ツールを検索して実行します |

詳しいキーバインドは [UserDocs/KEYBINDINGS.md](UserDocs/KEYBINDINGS.md) を参照してください。

## 基本的な使い方
MidFD の基本的な操作の流れは次のとおりです。

1. カーソルキーでファイルやフォルダを選択する
2. Enter で開く、または内蔵ビューアで表示する
3. 必要なファイルをマークする
4. コピー、移動、削除、リネームなどを実行する
5. よく使う場所は QuickAccess に登録する
6. 迷ったら Command Palette から機能を検索する

詳細な使い方は [UserDocs/USER_GUIDE.md](UserDocs/USER_GUIDE.md) を参照してください。

MidFD は、日付ベースのバージョン表記を使用します。
