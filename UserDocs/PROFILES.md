# 初期オプションとキー操作体系

MidFD には、初回セットアップ時や設定から個別に有効化できる「初期オプション（高度な使い方）」と、キー操作の割り当てを切り替える「キー操作体系（操作プリセット）」があります。

## 初期オプション / 高度な使い方

一部の高度な管理機能や追加のファイル操作機能は、誤操作の防止や画面表示のシンプル化のため、標準状態ではオフになっています。
これらは、初回セットアップ画面でまとめてチェックを入れて有効化できるほか、設定画面の「操作」タブにある「高度な使い方 / 詳細オプション」セクションでいつでも個別に ON / OFF を切り替えることができます。

### 主な高度な機能（詳細オプション）

- **Workspace Snapshot**
  開いているタブやカーソル位置などの状態を保存・復元するワークスペース管理機能です。
- **MarkSlot 集合演算 / バックアップ**
  ファイル選択状態（MarkSlot）の重ね合わせ、集合演算（積、差、和など）やバックアップのエクスポート/インポート機能です。
- **Drag ZIP**
  ドラッグ＆ドロップにより、選択ファイルを即時ZIP化して外部アプリへ引き渡す高度な連携機能です。

通常の使用では、これらの項目をオフにした状態（標準状態）を推奨します。必要に応じて個別に有効化してください。

## キー操作体系（操作プリセット）
キー操作体系は、主にファンクションキーの割り当てを切り替える設定です。
高度な機能オプションの有効無効とは異なり、利用できる機能範囲自体を制限するものではありません。

| 種類 | 内容 |
|---|---|
| 標準 | 現代的なショートカット中心の操作体系 |
| FD互換 | Fキー中心の操作体系 |

### 標準
標準は、現代的なショートカット操作を中心にした操作体系です。
Browser画面では、通常のFunctionバーとショートカット中心の導線を使います。

主な操作:

| 操作 | キー |
|---|---|
| 開く / 表示 | Enter |
| 関連付けで開く | Z |
| コマンド実行 | X |
| PowerShellを開く | H |
| コマンドプロンプトを開く | Shift+H |
| 再読込 | Ctrl+R |
| フィルタ | Ctrl+F |
| コマンドパレット | Ctrl+Shift+P |

### FD互換
FD互換は、Fキー中心の操作体系です。

> [!NOTE]
> 本書でいう「FD互換」は、主にキー操作体系や表示上の名称です。
> オリジナルの FD との完全互換を意味するものではありません。

FD風の操作感を重視し、Functionバーの既定割り当てや見え方をFD寄りにします。
主な違いは、ファンクションキー割り当てとFunctionBar表示です。

## 推奨設定
初めて使う場合は、次の組み合わせを推奨します。

* **初期オプション**: すべてオフ（必要になったら個別に設定の「操作」から有効化）
* **キー操作体系**: 標準

FD系ファイラの操作に慣れている場合は、キー操作体系だけ「FD互換」に変更することをおすすめします。
これらの設定は、初回セットアップ画面で簡単に切り替えることができ、後からいつでも変更可能です。
