# 使い方ガイド

MidFD は、FDライクな操作感を目指した Windows 向け軽量ファイラーです。
キーボードを主体とした軽快なファイル操作を実現しつつ、現代の Windows 利用環境に合わせた独自の機能差分（タブ機能など）を取り入れています。

> [!NOTE]
> MidFD はオリジナルの FD との完全互換を目的としたものではありません。
> 昔ながらのファイラー文化の良さを参考にしつつ、現代の Windows 環境向けに独自に設計されたアプリケーションです。
>
> キーボード中心で素早くファイルを見て、選び、整理し、必要に応じて外部ツールや shell へつなぐことを重視しています。
> コマンドプロンプト、PowerShell、Windows Terminal、WSL、Git Bash などをよく使う方が、Explorer とコマンドラインの間で使える軽量な GUI 補助ツールとして使うことも想定しています。

このページでは、MidFD の基本的な使い方を説明します。

## 配色

設定の「配色」タブでは、表示色プリセットを選択できます。

プリセットは `#RRGGBB` または RGB 値で編集できます。

編集した配色は名前を付けて複数保存できます。

保存したユーザープリセットは表示色リストから選択でき、不要になったものは削除できます。

## 基本画面
MidFD の中心は、ファイルやフォルダを表示する Browser 画面です。

Browser 画面では、次のような操作を行います。

- ファイルやフォルダを選択する
- Enter で開く、または内蔵ビューアで表示する
- 必要なファイルをマークする
- コピー / 移動 / 削除 / リネームを行う
- タブやカテゴリで作業場所を切り替える
- QuickAccess でよく使う場所へ移動する
- Command Palette から機能や外部ツールを実行する

- 情報...: 現在ドライブ、メモリ、システム情報を確認できます。

## 操作カスタマイズ

設定画面の「操作 / 入力」から、Browser 画面向けの操作カスタマイズを行えます。

### マウスジェスチャー割り当て

- Browser 画面の右ドラッグジェスチャーを Command へ割り当てできます。
- 1方向4種（L / R / U / D）と2方向12種の合計16パターンに対応します。
- ジェスチャーの無効化、既定に戻す、再起動後の復元に対応します。
- 右ドラッグ中は、方向列と割り当て Command 名がステータス表示されます。
- 右ドラッグ中は Browser 一覧上に軌跡が表示されます。

### キーバインドカスタマイズ

- Browser 画面の主要 Command に対してキー割り当てを変更できます。
- 無効化、選択 Command の既定復帰、すべて既定に戻す、競合検出に対応します。
- 操作プリセット（MidFD標準 / FD/WinFD互換）は既定キーセットを決めるもので、ユーザー設定はその上書きとして扱われます。
- 対象は Browser 画面です。ImageViewer、TextViewer、ArchiveContents、各種 Dialog のキー操作は今回のカスタマイズ対象外です。

### ファンクションバー割り当て

- Browser 画面下部に表示されるファンクションバーについて、F1〜F12 の各スロットに割り当てる任意の Command を設定画面から変更できます。
- プロファイル（MidFD標準 / FD/WinFD互換）ごとに独立した割り当てを保持します。
- **4レイヤー対応 (タブ表示)**: 「通常 F1〜F12」「Shift+F1〜F12」「Ctrl+F1〜F12」「Alt+F1〜F12」のタブを切り替えて、それぞれの面に個別に Command を割り当て可能です。
- 各スロットの「表示名」は直接編集できます。表示名は半角換算4表示セルまでで、空欄にすると既定表示へ戻ります。
- リストビューの各行をダブルクリックすることで、コマンド選択画面から機能を選択できます。
- ユーザーにとって判読しやすい「キー / 表示名 / 割り当て / 既定 / 説明」の5列で一覧表示され、注意が必要な危険操作（ファイル削除など）は説明欄に「確認あり。」と注記されます。
- FD/WinFD互換プロファイルでは、表示名が実際のファンクションバー描画に適合した英語短縮ラベル（`help / eXec / Copy / Delet / Renam` など）で表示され、説明欄に日本語詳細が表示されます。
- 割り当てた内容は、画面下部の Functionバーのボタン表示・マウスクリック時の実行・および対応する物理Fキー入力時に一元的に適用されます。
- Shift / Ctrl / Alt レイヤー表示中は、Functionバー左端の keycap badge で現在のレイヤーを示します。
- **Fキーホバー時のToolTip案内**: 設定画面の「Fキーホバー時に詳細説明を表示する」を有効にすると、Browser画面でFunctionバー上にマウスを置いた際、割り当てたコマンドの表示名や詳細説明、キーヒントが ToolTip として案内表示されます。
- この設定の対象は Browser 画面です。ImageViewer、TextViewer、ArchiveContents、各種 Dialog の専用Fキー操作は影響を受けません。

## 初回起動

MidFD を初めて起動すると、「MidFD 初回セットアップ」画面が表示されます。

この画面では、ファンクションキー配置、動画ファイルの Enter 動作、外部連携に加えて、「初期オプション」として主要な任意設定を選べます。

### 初期オプション

初回セットアップでは、次のような項目を個別に選べます。
同じ項目は後から「設定 > 操作」の「高度な使い方 / 詳細オプション」でも変更できます。

- Drag ZIP を使う
- Drag ZIP に内容一覧manifestを同梱する
- マウスジェスチャーを使う
- Functionバーの詳細説明を表示する
- 前回フォルダを復元する
- Workspace Snapshot / 作業状態復元を使う

`Workspace Snapshot / 作業状態復元を使う` を有効にすると、Workspace Snapshot や MarkSlot の拡張管理導線を表示します。

詳しくは [PROFILES.md](PROFILES.md) を参照してください。

### 操作スタイル

初回セットアップでは、次の基本操作も選択できます。

- FD互換のファンクションキー配置を使う
- 動画ファイルを Enter で外部再生する

「動画ファイルを Enter で外部再生する」を有効にした場合、動画ファイルの Enter は外部再生、Ctrl+Enter は静止画プレビューになります。

無効の場合は、従来どおり Enter / V が静止画プレビュー、Ctrl+Enter が外部再生です。

### 外部連携

初回セットアップでは、任意で次の外部連携を設定できます。

- 7-Zip パス
- 動画ツールフォルダ
- 外部エディタ

未設定でも基本操作は可能です。

動画の外部再生は、ffplay が未設定でも Windows の関連付けで開けます。
動画の静止画プレビューには ffmpeg.exe が必要です。

これらの設定は、後から「設定 > 操作 / 外部連携」で変更できます。

### 初回セットアップをもう一度開く

初回セットアップは、設定後も「設定」画面の「起動・ログ」から再表示できます。

これは全設定の初期化ではなく、初期オプション、Fキー配置、動画Enter動作、外部連携などの基本設定を再設定するための画面です。

## 設定画面の概要

設定画面は、次のタブに分かれています。

| タブ | 主な内容 |
|---|---|
| 表示 | 一覧表示、Viewerフォント、動画プレビュー表示など |
| 配色 | 表示色プリセット、ユーザープリセット、一覧色、UI基調色 |
| 操作 | ファイル操作、Drag ZIP、高度な使い方、貼り付け、Functionバー補助表示など |
| 入力割り当て | キーバインド、Functionバー、マウスジェスチャー |
| 外部連携 | 7-Zip、外部エディタ、動画ツール、外部ツール定義 |
| 起動・ログ | 初回セットアップ再表示、復元、ログ設定 |

## 基本操作の流れ
MidFD の基本的な操作の流れは次のとおりです。

1. カーソルキーでファイルやフォルダを選択する
2. Enter で開く、または内蔵ビューアで表示する
3. 必要なファイルをマークする
4. コピー、移動、削除、リネームなどを実行する
5. よく使う場所は QuickAccess に登録する
6. 迷ったら Command Palette から機能を検索する

## ファイルやフォルダを選択する
ファイル一覧では、カーソルキーで項目を選択します。

| 操作 | キー |
|---|---|
| 上下移動 | ↑ / ↓ |
| ページ移動 | PageUp / PageDown |
| 履歴を戻る / 進む | Alt+← / Alt+→ |

`Home` はファイルのみ全選択、`End` はディレクトリを含めた全選択です。先頭/末尾への移動は Functionキーや割り当て Command から実行します。

## ファイルを開く
選択したファイルやフォルダは、Enter で開きます。

| 操作 | キー | 説明 |
|---|---|---|
| 開く / 表示 | Enter | フォルダを開く、またはファイルを内蔵ビューアで表示します |
| 関連付けで開く | Z | OS の関連付けでファイルを開きます |

Enter は MidFD 内での表示を優先します。
Z は Windows の関連付けに従って開きます。

## Viewerを使う
Enter でファイルを開くと、内蔵 Viewer で表示できる場合があります。

主な対象:

- テキストファイル
- 画像ファイル
- SVGファイル
- 大きなテキストファイル

Viewer を閉じるには Esc を押します。

| 操作 | キー |
|---|---|
| Viewerを閉じる | Esc |
| コピー | Ctrl+C |
| 全選択 | Ctrl+A |

通常テキスト Viewer では Ctrl+A による全文選択が使えます。
巨大ファイル向けの LargeText Viewer では、安全性のため一部操作が異なる場合があります。

### 画像ビューア

- 画像ビューアではドラッグで矩形選択し、`Ctrl+C` で選択範囲のみをコピーできます。選択がない場合は全画像コピーです。
- 右90度回転、左90度回転、左右反転、上下反転に対応しています。変換は表示専用で、元ファイルは変更しません。
- 「画像情報」では、通常画像の基本情報に加えて、VideoStill 時はコンテナ形式、動画codec、音声codec、動画長、解像度、フレームレート、ビットレートも確認できます。
- モデルレス表示中に MainForm 側がアクティブでも、`Esc` で開いている画像ビューアを閉じられます。

## 動画静止画プレビュー (VideoStill)
動画ファイルに対して、内蔵の画像ビューアーを用いた静止画プレビューを提供します。

### 基本操作
- 動画ファイルを選択した状態で、`Enter` または `V` を押すと、`MidFD Image Viewer`（画像プレビュー画面）が起動し、動画の静止画プレビューが表示されます。
- 初期表示位置は通常 `0秒` です。設定で静止画位置（スキップ秒数）を変更している場合は、その秒数から表示します。
- スキップ秒数は600秒といった固定上限に丸められることなく、設定された通りの秒数が制限なしで使用できます。
- 画像プレビュー画面が開いている状態（再利用設定が有効な場合）では、動画ファイルをカーソル移動で選択するだけで、自動的に画像プレビュー画面側がその動画の静止画に更新されます。
- 画像プレビュー画面の下部にある細いシークバーをクリックすることで、動画内の任意の位置へシークできます。
- キーボード操作：
  - `←` / `→`：指定された秒数ステップ（動画長に応じて自動調整）で位置を前後にシーク。
  - `Shift + ←` / `Shift + →`：大きなステップ（5秒〜30秒）で位置を前後にシーク。
  - `Home`：動画の先頭（0秒）へ位置を戻します。
  - `Ctrl + Enter`：現在プレビューしている位置（付近）から外部再生ツール（`ffplay.exe`等）で再生を開始する。

### 外部ツールとの連携
動画静止画プレビューには、外部の `ffmpeg.exe` が必要です。

外部再生は、`ffplay.exe` が設定されている場合は ffplay を使用し、未設定の場合は Windows の関連付けで開きます。
`ffprobe.exe` が利用できる場合は、動画の総時間取得などに使用します。
- **ffmpeg.exe**: 静止画の生成に使用します。
- **ffplay.exe**: `Ctrl + Enter` での外部再生に使用します。
- **ffprobe.exe**: 動画の総時間（長さ）の取得に使用します。

設定は「設定」の「外部連携」タブにある「動画ツールフォルダ」で行います。

`ffmpeg.exe`、`ffplay.exe`、`ffprobe.exe` が同じフォルダに配置されている場合、MidFD はそれぞれを役割別に自動検出・解決します。

> [!NOTE]
> - MidFD には `ffmpeg` ツール群は同梱されていません。利用者側で入手・設定を行ってください。
> - `Ctrl + Enter` による外部再生開始位置は、`ffplay` のシークの仕様上、厳密なプレビューフレームとの一致ではなく、その近傍（キーフレーム等の位置）からの再生開始となります。
> - `ffprobe.exe` が検出できない、または動画の総時間取得に失敗した場合は、位置バーが無効状態（「←/→:位置 (動画長不明のため位置バー無効)」）として表示され、位置バーをクリックしたシーク等は無効化されます（この場合、指定した秒数が実際の動画長を超えるときは静止画を取得できず空表示になる制約があります）。

## マークする
MidFD では、ファイルやフォルダをマークして、まとめて操作できます。

| 操作 | キー | 説明 |
|---|---|---|
| マーク切り替え | Space | 選択項目のマーク状態を切り替えます |
| マーク切り替え | Insert | 選択項目をマークし、次の項目へ移動します |
| マウスマーク | Ctrl+左クリック | クリックした項目のマークON/OFFを切り替えます |
| マウスマーク | Shift+左クリック | アンカーからクリック位置まで範囲マークします |
| マウスマーク | Ctrl+Shift+左クリック | Shift+左クリックと同じく範囲マークします |
| マーク操作 | Tab | マーク関連操作に使います |

マーク対象がある場合、コピーや移動などの操作でマーク対象が優先される場合があります。

## MarkSlotを使う
MarkSlot は、マーク状態を保存・復元する機能です。

たとえば、複数のファイルをマークした状態をスロットに保存しておくと、後から同じマーク状態を復元できます。

標準状態では、MarkSlot の基本保存・復元を利用できます。

高度な使い方（詳細オプション）が有効になっている場合、MarkSlot 集合演算や backup export / import などの追加導線を利用できます。

## コピー / 移動 / 削除 / リネーム
ファイル操作は、メニュー、コンテキストメニュー、Command Palette、ファンクションキーなどから実行できます。

主な操作:

| 操作 | 内容 |
|---|---|
| コピー | 選択項目またはマーク対象をコピーします |
| 移動 | 選択項目またはマーク対象を移動します |
| 削除 | 選択項目またはマーク対象を削除します |
| リネーム | 選択項目の名前を変更します |

ファイル操作は取り消しが難しい場合があります。
重要なファイルを扱う場合は、内容をよく確認してから実行してください。

### Drag ZIP handoff

設定の「操作 / 入力」>「ファイル操作」では、Shift/Ctrl+ドラッグでマーク対象をZIP化して渡すかどうかを切り替えられます。

- 親設定が OFF の場合、Shift/Ctrl+複数マークドラッグでも通常の複数ファイルドラッグになります。
- 親設定が ON の場合、Shift/Ctrl+複数マークドラッグで `MidFD-drag-{hash}.zip` 形式のZIP 1個を渡します。
- 子設定を ON にすると、ZIPのルートに `_midfd_drag_manifest.txt` を同梱します。
- manifest には対象ファイル一覧、作成時刻、hash、基準ディレクトリ、相対パス、サイズ、更新時刻が含まれます。
- ChatGPT等へ複数ソースをまとめて渡す場合に、ZIP内の対象一覧を確認しやすくする用途です。
- manifest にはローカルパス情報を含む場合があります。

### クリップボード貼り付け

- 設定で有効にすると、テキストクリップボードを `.txt` ファイルとして貼り付けできます。
- この機能は誤作成防止のため既定で OFF です。
- 画像貼り付け、テキスト貼り付け、ファイルコピー貼り付けで新規作成されたファイルは `Ctrl+Z` で取り消せます。
- 貼り付けで作成したファイルの Redo 再作成は対象外です。

### Copy/Move先入力の履歴と補完
Copy/Move ダイアログの宛先入力欄では、過去に移動・コピーが成功した宛先を履歴として利用できます。

Logdsk / Move / Copy の宛先履歴は同じ履歴を共有します。

- `↑ / ↓`: 履歴選択
- `Tab`: ディレクトリ補完（補完表示中の `↑ / ↓` は補完候補選択）

履歴は操作成功時のみ保存され、Cancelや失敗時は追加されません。

## タブを使う
タブを使うと、複数の作業場所を切り替えながら操作できます。

たとえば、次のような使い方ができます。

- 作業フォルダ用のタブ
- 画像フォルダ用のタブ
- ダウンロードフォルダ用のタブ
- 一時作業用のタブ

タブの切り替えには Ctrl+Tab などを使います。

| 操作 | キー |
|---|---|
| タブ切り替え | Ctrl+Tab |
| 同一カテゴリ内の前後タブ移動 | Ctrl+Left / Ctrl+Right |

## カテゴリを使う
カテゴリを使うと、タブを用途ごとに整理できます。

例:

- 作業
- 素材
- 画像
- 一時
- アーカイブ

タブが増えてきた場合は、カテゴリで整理すると作業場所を見失いにくくなります。

## QuickAccessを使う
QuickAccess は、よく使う場所へすばやく移動するための機能です。

`Q` またはメニューから開き、登録先、最近使った場所、戻る/進む履歴をまとめて確認できます。

例:

- 作業フォルダ
- ダウンロードフォルダ
- 画像素材フォルダ
- プロジェクトフォルダ
- 一時保存フォルダ

QuickAccess では、表示名、移動先、状態、対象種別を一覧で確認できます。存在しないパスは移動前に止まり、状態列で理由を確認できます。

登録先タブでは、フォルダ登録、編集、削除ができます。最近 / 履歴タブでは、選択中の場所へ移動するほか、その場所を登録先へ追加できます。

外部コマンドを登録している場合は、対象（現在地、選択項目、選択ファイル、選択フォルダ、マーク項目）と作業ディレクトリの扱いを確認して実行できます。

## フィルタを使う
フィルタを使うと、一覧に表示する項目を絞り込めます。

| 操作 | キー |
|---|---|
| フィルタ | Ctrl+F |

ファイル数が多いフォルダで、目的のファイルを探すときに便利です。

## ソートを使う
ソートを使うと、一覧の並び順を変更できます。

主な並び替えの例:

- 名前順
- 拡張子順
- サイズ順
- 更新日時順

ソートは、メニューやファンクションキーから実行できます。
ファンクションキー割り当ては、キー操作体系によって変わります。

## ドライブ/ディレクトリの移動 (Logdsk)
F9キー（FD互換ファンクションキーの場合）等で起動できる「Logdsk (ディレクトリ移動)」ダイアログでは、以下の機能が利用できます。

- **移動履歴の呼び出し**: 過去に移動が成功したディレクトリが履歴として保存され、入力欄で `↑` / `↓` キーを押すことで履歴を順次呼び出せます。
- **履歴リストのドロップダウン**: コントロールの▼ボタンを押すことで、過去の移動履歴の一覧からマウスやキーで選択して移動できます。
- **Tabキーによるパス補完**: 入力中のディレクトリパスを `Tab` キーで自動補完できます（補完ポップアップが表示されているときは、`↑` / `↓` キーは補完候補の選択として機能します）。

## 一覧表示モード
一覧表示は次の3モードを切り替えできます。

- ファイル名のみ
- ファイル名 + サイズ
- ファイル名 + サイズ + 更新日時

切替方法:

- 設定画面の一覧表示モード
- 表示メニュー
- `Ctrl+1 / Ctrl+2 / Ctrl+3`
- FD/WinFD互換操作プリセット時は、同じ列数キー再押下でローテーション

## 一覧表示の色（配色タブ）

一覧表示の色は、「設定」 > 「配色」タブで設定します。

- 表示色プリセット（built-in / ユーザープリセットをシームレスに切替）
- `#RRGGBB` と RGB による色編集（色見本やプレビューによる同期表示に対応）
- ユーザープリセットの登録・上書き・削除
- 固定サンプルで通常行/選択行/属性色を確認

補足:

- built-in プリセットは上書き/削除できません。built-in配色を直接編集した場合は、自動的に新しいユーザープリセット（`color n`）が作成されて保存されます。
- ユーザープリセットは複数保存可能で、ユーザープリセット選択中に直接編集した場合は上書き保存されます。
- 設定画面の「適用」で即時反映、「OK」で保存、「キャンセル」で破棄されます。
- 選択行は背景中心に変わり、ファイル種別・属性色は維持されます。選択行をアンダーライン表示にする設定も可能です。
- マークはファイル名全体ではなく `*` 記号で示します。
- UI全体の基調色（Menu、Header、Status、Viewer等）は、「表示色連動」の自動調整に任せるか、設定画面の「手動指定する」チェックボックスをONにして手動カスタマイズするかの2系統を選択可能です。
- Viewer（テキスト/バイナリダンプ等）の標準配色（手動指定OFFまたはClassicCyanプリセット時）は、従来MidFD寄りの「濃紺（`#000040`）」背景を既定値としています。

## カーソル表示
設定により、選択行を背景ハイライトではなくアンダーラインで表示できます。
属性色やファイル種別色を維持したまま現在位置を示したい場合に有効です。

## Explorerで開く
現在のフォルダは `Alt+F2` またはメニューから Explorer で開けます。
MidFDで場所を選んでから Explorer へ渡す導線として使えます。

## アーカイブ操作 (7-Zip / Windows 標準連携)
MidFD はアーカイブファイルの作成・展開に対応しています。

主な用途:

- 圧縮
- 解凍
- CRC / SHA などのハッシュ確認 (7-Zip 導入時のみ)

### アーカイブ操作 (7-Zip 連携)
7-Zip がインストールされている場合、MidFD は 7-Zip を優先的に使用します。
高速な処理、豊富な形式への対応、暗号化、分割アーカイブなどの高度な機能を利用できます。

### Windows 標準機能 (tar.exe) によるフォールバック
7-Zip がインストールされていない環境でも、Windows 11 (24H2 以降推奨) 標準の `tar.exe` を使用して、主要な形式 (`zip`, `7z`, `tar`) の作成・展開が可能です。

※ 7-Zip なしの環境では、暗号化アーカイブや分割アーカイブの処理、詳細なハッシュ確認など、一部の機能に制限があります。

### アーカイブ内ファイル一覧 (Archive Contents)

ZIP 等のアーカイブファイルを選択して `Enter` またはダブルクリックすることで、アーカイブ内のファイル一覧を仮想的にブラウズできます。

- **移動とプレビュー**:
  - フォルダまたは `..`（親ディレクトリ）を選択して `Enter` を押すと、アーカイブ内の階層を移動できます。
  - テキストファイル（`.txt` や `.md` など）を選択して `Enter` を押すと、独立したテキストプレビュー画面がモデルレス（別ウィンドウ）で開きます。
  - プレビュー画面が開いた状態のまま、背後のアーカイブ一覧で `↑` / `↓` キー等で選択ファイルを移動すると、プレビュー画面内の表示テキストが即座に追従して自動更新されます（カーソル追従）。
  - プレビュー対象外（フォルダや非対応形式のファイルなど）を選択した場合は、プレビュー画面は閉じずに「フォルダはプレビューできません」などの案内メッセージを表示します。また、プレビュー不可能なファイル選択中の `Enter` は Beep 音を鳴らして通知します。
- **解凍（マーク/選択ファイルの展開）**:
  - `Space` キーで一覧の選択項目にマーク（`*` 記号）を付け外しできます。
  - `U` キー（または画面下部の「マーク解凍...」ボタン）を押すと、マークされたエントリを解凍先指定で展開します。
  - マークが1件もない場合は、現在カーソルが合っている対象を選択解凍します。
  - ファイルを選択している場合は、その1ファイルを解凍します。
  - 実フォルダを選択している場合は、そのフォルダ配下の実ファイルを解凍対象にします。
  - `..` や解凍対象のない空フォルダの場合は、解凍に進まず安全に警告して停止します。
  - ReadOnlyタブでアーカイブを開いた場合、書き込み保護のため `U` キーによる解凍操作や、各種圧縮操作（ボタン含む）は無効化され動作しません。
  - 7-Zipがインストールされていない環境でも、Windows標準の `tar.exe` が検出できれば、ZIPアーカイブ等の選択エントリ解凍（ZIP fallback）が機能します。

## シンボリックリンク / ジャンクションの安全境界

MidFD のファイル操作では、`symlink` / `junction` / `reparse point` を通常ディレクトリとして再帰追跡しない方針です。

- 削除: リンク先実体には潜らず、リンク本体側を対象に処理します。
- 移動: 同一ドライブ移動では通常どおり処理し、別ドライブ fallback で危険な `copy+delete` が必要になる reparse point directory は安全のためブロックします。
- コピー: リンク先展開コピーを避けるため、reparse point directory のコピーは安全のためブロックします。

## 切り取り貼り付けの安全確認と Undo / Redo

- 複数項目（2件以上）の切り取り貼り付けでは、実行前に確認ダイアログを表示します。
- 成功した切り取り貼り付け移動は、このセッション中に限り Undo / Redo できます。
- 本Phaseで追加した Undo / Redo 対象は、成功した切り取り貼り付け移動です。
- 移動元や移動先が外部で変更されると、Undo / Redo は安全のため停止することがあります。

## 外部ツール
外部ツールを登録すると、MidFD から任意のツールを呼び出せます。

たとえば、次のような用途に使えます。

- エディタで開く
- PowerShellスクリプトを実行する
- 画像ツールを開く
- 差分ツールを呼び出す
- 選択ファイルを外部コマンドへ渡す

外部ツールは環境依存になりやすいため、設定内容を確認してから使用してください。

外部ツールには、信頼できる場所にある実行ファイルを指定してください。
存在しないパスや実行不能なパスを設定した場合は、安全に通知して処理を止めます。

### Alt slot launcher

登録済み外部ツールには、Alt+英数字の slot を設定できます。

- Alt 単体で launcher を表示します。
- `↑ / ↓ / Home / End / PageUp / PageDown` で launcher 内の選択を移動します。
- `Enter` で選択中の slot を起動します。
- `Esc` で launcher を閉じます。
- `Alt+← / Alt+→` は launcher では処理せず、Browser の履歴戻る / 進むに使います。

Alt+英数字の外部ツール slot と、Alt+F1〜F12 の Function layer は別の導線です。

## Command Palette
Command Palette は、機能や外部ツールを検索して実行するための補助導線です。

| 操作 | キー |
|---|---|
| Command Paletteを開く | Ctrl+Shift+P |

主な用途:

- 機能名で検索する
- 現在ディレクトリを再読込する
- 現在パスをコピーする
- 選択項目のフルパスをコピーする
- Explorerで開く
- PowerShellをここで開く
- 外部エディタで開く
- MarkSlot 管理を開く
- 外部ツールを実行する

迷った場合は、Command Palette から探すのが便利です。

## PowerShell / コマンドプロンプトを開く
現在フォルダでターミナルを開けます。

| 操作 | キー |
|---|---|
| PowerShellを開く | H |
| コマンドプロンプトを開く | Shift+H |

現在表示中のフォルダを起点に作業したいときに使います。

## マウスジェスチャー
Browser画面では、右クリックドラッグでマウスジェスチャーを利用できます。

- 既定では、戻る / 進む / 親ディレクトリへ移動 / 再読込などの操作が割り当てられています。
- 設定画面から各ジェスチャーの割り当て変更、無効化、既定復帰ができます。
- 入力中は方向列と割り当て Command 名がステータス表示され、一覧上に軌跡も表示されます。

## キー操作体系を変更する
MidFD には、キー操作体系として「標準」と「FD互換」があります。

| 種類 | 内容 |
|---|---|
| 標準 | 現代的なショートカット中心の操作体系 |
| FD互換 | Fキー中心の操作体系 |

FD互換は、主にファンクションキー割り当てと FunctionBar 表示の違いです。

詳しくは [KEYBINDINGS.md](KEYBINDINGS.md) を参照してください。

## 高度な使い方と追加導線オプション
一部の高度なファイル管理機能や追加導線は、初期状態ではオフになっています。

設定画面の「操作」タブにある「高度な使い方 / 詳細オプション」セクションで、必要な項目を個別に有効化できます。

有効化することで、Workspace Snapshot、MarkSlot 集合演算、拡張画像連携などの追加導線を使えるようになります。通常の使用では、これらをオフにした状態（標準状態）を推奨します。

詳しくは [PROFILES.md](PROFILES.md) を参照してください。
