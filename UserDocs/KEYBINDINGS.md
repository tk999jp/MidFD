# キーバインド
MidFD は、キーボード操作を重視したファイルマネージャです。

このページでは、MidFD の主なキーバインドをまとめます。

## 操作体系について
MidFD には、キー操作体系として「標準」と「FD互換」があります。

| 種類 | 内容 |
|---|---|
| 標準 | 現代的なショートカット中心の操作体系 |
| FD互換 | Fキー中心の操作体系 |

> [!NOTE]
> 本書でいう「FD互換」は、主にキー操作体系や表示上の名称です。
> オリジナルの FD との完全互換を意味するものではありません。

この設定は、主にファンクションキー割り当てと FunctionBar 表示を切り替えるものです。

利用できる機能の範囲は、「実用安定版（推奨）」「高度機能α版」の利用モードで切り替わります。

## 最初に覚えるキー
まずは、次のキーを覚えると基本操作を始められます。

| 操作 | キー | 説明 |
|---|---|---|
| 開く / 表示 | Enter | 選択項目を開く、または内蔵ビューアで表示します |
| 関連付けで開く | Z | OS の関連付けでファイルを開きます |
| コマンド実行 | X | 選択項目や現在フォルダを使ってコマンドを実行します |
| PowerShell を開く | H | 現在フォルダで PowerShell を開きます |
| コマンドプロンプトを開く | Shift+H | 現在フォルダでコマンドプロンプトを開きます |
| 再読込 | Ctrl+R | 現在ディレクトリを再読込します |
| フィルタ | Ctrl+F | 一覧を絞り込みます |
| コマンドパレット | Ctrl+Shift+P | 機能や外部ツールを検索して実行します |

## Browser操作
ファイル一覧画面で使う主な操作です。

| 操作 | キー | 説明 |
|---|---|---|
| カーソル移動 | ↑ / ↓ | 選択項目を上下に移動します |
| ページ移動 | PageUp / PageDown | 一覧をページ単位で移動します |
| 先頭へ移動 | Home | 一覧の先頭へ移動します |
| 末尾へ移動 | End | 一覧の末尾へ移動します |
| 開く / 表示 | Enter | 選択項目を開く、または内蔵ビューアで表示します |
| 関連付けで開く | Z | OS の関連付けで開きます |
| Explorerで開く | Alt+F2 | 現在フォルダを Explorer で開きます |
| コマンド実行 | X | コマンド実行ダイアログを開きます |
| PowerShell を開く | H | 現在フォルダで PowerShell を開きます |
| コマンドプロンプトを開く | Shift+H | 現在フォルダでコマンドプロンプトを開きます |
| 元に戻す | Ctrl+Z | 直前のファイル操作（対応操作のみ）を元に戻します |
| やり直し | Ctrl+Y | 元に戻したファイル操作（対応操作のみ）を再実行します |
| 再読込 | Ctrl+R | 現在ディレクトリを再読込します |
| フィルタ | Ctrl+F | 一覧を絞り込みます |
| コマンドパレット | Ctrl+Shift+P | コマンドパレットを開きます |

## 表示モード

| 操作 | キー | 説明 |
|---|---|---|
| ファイル名のみ | Ctrl+1 | 一覧をファイル名のみ表示にします |
| ファイル名 + サイズ | Ctrl+2 | 一覧にサイズを表示します |
| ファイル名 + サイズ + 更新日時 | Ctrl+3 | 一覧にサイズと更新日時を表示します |
| 表示モードローテーション | 同じ列数キー再押下 | FD/WinFD互換操作プリセット時のみ、同じ列数キー再押下で表示モードを切り替えます |

## Logdsk (ディレクトリ移動) 内での操作
Logdsk (ディレクトリ移動) ダイアログ内でのキー操作です。

| 操作 | キー | 説明 |
|---|---|---|
| 履歴選択 | ↑ / ↓ | 過去に移動成功したディレクトリ履歴を巡回選択します |
| ドロップダウン表示 | Alt + ↓ または ▼クリック | 過去の履歴を一覧からマウスやカーソルキーで選択できます |
| パス補完 | Tab | 入力中のパスを自動補完します（補完ポップアップ表示中は、↑/↓ は補完候補の選択になります） |

## Move先入力欄での操作
Moveダイアログの移動先入力欄では、Logdskと同じ責務分離で操作します。

| 操作 | キー | 説明 |
|---|---|---|
| 履歴選択 | ↑ / ↓ | 過去にMove成功した移動先履歴を巡回選択します |
| ドロップダウン表示 | Alt + ↓ または ▼クリック | Move先履歴を一覧から選択できます |
| パス補完 | Tab | 入力中のディレクトリを補完します（補完ポップアップ表示中のみ ↑/↓ は補完候補選択） |

## ファイル操作
ファイル操作は、メニュー、コンテキストメニュー、Command Palette、ファンクションキーなどから実行できます。

| 操作 | 説明 |
|---|---|
| コピー | 選択項目またはマーク対象をコピーします |
| 移動 | 選択項目またはマーク対象を移動します |
| 削除 | 選択項目またはマーク対象を削除します |
| リネーム | 選択項目の名前を変更します |
| ソート | 一覧の並び順を変更します |
| フィルタ | 一覧を条件で絞り込みます |

ファンクションキー割り当ては、標準 / FD互換の設定によって変わります。

## マーク操作
MidFD では、対象ファイルをマークしてまとめて操作できます。

| 操作 | キー | 説明 |
|---|---|---|
| マーク切り替え | Space | 選択項目のマーク状態を切り替えます |
| マーク切り替え | Insert | 選択項目をマークし、次の項目へ移動します |
| マーク操作 | Tab | マーク関連操作に使います |

MarkSlot を使うと、マーク状態を保存・復元できます。

## Archive Contents (ZIP内閲覧) 内での操作
ZIP アーカイブ内のファイル一覧（Archive Contents）ダイアログ内でのキー操作です。

| 操作 | キー | 説明 |
|---|---|---|
| 階層移動 / プレビュー | Enter | フォルダ/`..` は移動（階層移動）。テキストファイルは独立プレビュー表示（モデルレス）。非対応ファイルはBeep。 |
| マーク切り替え | Space | 選択項目のマーク状態（`*`）を切り替えます |
| マーク切り替え | Insert | 選択項目をマークし、次の項目へ移動します |
| 解凍 | U | マークがある場合はマークされたファイルを解凍。マークがない場合は現在選択中の対象を解凍し、実フォルダ選択時は配下の実ファイルを対象にします。`..` や空フォルダは安全に警告して停止し、ReadOnlyタブでは解凍不可です。 |
| 閉じる / キャンセル | Esc | ダイアログを閉じます。プレビューウィンドウが開いている場合はプレビューも自動で閉じます。 |

実用安定版（推奨）では、MarkSlot の基本保存・復元を利用できます。
高度機能α版では、MarkSlot 集合演算などの高度機能が利用できる場合があります。

## 切り取り貼り付けの安全確認

- 複数項目（2件以上）の切り取り貼り付けは、実行前に確認ダイアログを表示します。
- Undo / Redo は、成功した切り取り貼り付け移動に対してセッション中のみ有効です。
- 本Phaseで追加した Undo / Redo 対象は、成功した切り取り貼り付け移動です。

## タブ / カテゴリ操作
タブとカテゴリを使うと、作業場所を分けて管理できます。

| 操作 | キー | 説明 |
|---|---|---|
| タブ移動 | Ctrl+Tab | タブを切り替えます |
| 同一カテゴリ内の前後タブ移動 | Ctrl+Left / Ctrl+Right | 現在カテゴリ内で前後のタブへ移動します |

タブやカテゴリに関する操作は、メニューやコンテキストメニューからも実行できます。

## マウス操作 / ジェスチャー

| 操作 | 入力 | 説明 |
|---|---|---|
| 戻る / 進む | 右クリックドラッグ | Browser の移動履歴を戻る / 進む操作として使います |

## Viewer操作
内蔵ビューアでは、テキストや画像を表示できます。

| 操作 | キー | 説明 |
|---|---|---|
| 表示を閉じる | Esc | Viewerを閉じてBrowserへ戻ります |
| 全選択 | Ctrl+A | 通常テキストViewerで全文選択します |
| コピー | Ctrl+C | 選択内容をコピーします |

巨大ファイル向けの LargeText Viewer では、安全性のため通常テキストViewerと一部操作が異なる場合があります。

### 画像プレビュー画面での動画静止画プレビュー (VideoStill) 操作
既定では、動画ファイルに対して `Enter` または `V` で画像プレビュー画面を開きます。
設定で「動画 Enter で外部再生する」を有効にしている場合、`Enter` は外部再生、`V` は静止画プレビューになります。

| 操作 | キー | 説明 |
|---|---|---|
| シーク（戻る/進む） | ← / → | 動画内の位置を前後に変更します（動画長に合わせて自動ステップ） |
| 大シーク（戻る/進む） | Shift + ← / Shift + → | 大きなステップで位置を変更します |
| 先頭へ戻る | Home | 動画の先頭（0秒）へ位置を戻します |
| 外部再生 | Ctrl+Enter | 現在プレビューしている位置から外部再生（ffplay等）を起動します |

### 動画ファイル

| キー | 動作 |
|---|---|
| Enter | 動画静止画プレビューを開く |
| V | 動画静止画プレビューを開く |
| Ctrl+Enter | 外部プレイヤーで動画を再生する |

設定で「動画 Enter で外部再生する」を有効にした場合は、次の動作になります。

| キー | 動作 |
|---|---|
| Enter | 外部プレイヤーで動画を再生する |
| Ctrl+Enter | 動画静止画プレビューを開く |
| V | 動画静止画プレビューを開く |

ffplay が設定されていない場合でも、外部再生は Windows の関連付けで開きます。
動画静止画プレビューには ffmpeg.exe が必要です。

## Command Palette
Command Palette は、機能や外部ツールを検索して実行するための補助導線です。

| 操作 | キー |
|---|---|
| Command Paletteを開く | Ctrl+Shift+P |

主な用途:

- 現在ディレクトリを再読込
- 現在パスをコピー
- 選択項目のフルパスをコピー
- MarkSlot 管理を開く
- 外部ツールを検索して実行

実用安定版（推奨）では、基本的な候補を中心に表示します。
高度機能α版では、より高度な候補が表示される場合があります。

## 標準ファンクションキー
標準のキー操作体系では、現代的なショートカット操作を中心にします。

Browser画面では FunctionBar を表示せず、一覧領域を広く使います。

| キー | 操作 |
|---|---|
| F1 | Help |
| F2 | Rename |
| F5 | Reload |
| F10 | Menu |
| F11 | Top |
| F12 | Bottom |

標準では、すべてのFキーに機能を詰め込むのではなく、よく使う操作に絞っています。

## FD互換ファンクションキー
FD互換は、Fキー中心の操作体系です。

Browser画面下部に FunctionBar を表示し、Fキー操作を確認しやすくします。

| キー | 操作 |
|---|---|
| F1 | Help |
| F2 | Check / Execute |
| F3 | Copy |
| F4 | Edit |
| F5 | Rename |
| F6 | Sort |
| F7 | Filter |
| F8 | Tree |
| F9 | Logdisk |
| F10 | Unpack |
| F11 | Top |
| F12 | Bottom |

FD/WinFD互換操作プリセット（操作プリセットが「FD/WinFD互換」の場合）では、以下のWinFD風ショートカットも利用できます（「MidFD標準」操作プリセットの時は動作しません）。
これらのショートカットは、Browser画面（ファイル一覧表示）時のみ有効です。内蔵Viewer表示中は、それぞれのViewer専用のキーバインド（たとえば Viewer 中での Shift+F3 による「前検索」など）が優先されます。

| キー | 操作 |
|---|---|
| Shift+F1 | 属性変更 |
| Shift+F3 | 移動 |
| Shift+F5 | ディレクトリ作成 |
| Shift+F6 | Shell起動 |
| Shift+F7 | 再読込 |
| Shift+F8 | 外部Editor |
| Shift+F9 | View |
| Shift+F10 | 圧縮 |
| Shift+Enter | 外部Editor |
| Alt+F5 | 設定 |
| Shift+Ctrl+C | フルパスをコピー |

※ Shift+F4 は WinFD ではディレクトリ削除キーですが、誤操作リスク低減のため MidFD では非対象（未対応）です。エディタや削除のいずれにも接続せず、何もしません。

FD互換は、利用できる機能そのものを切り替えるものではありません。
主にファンクションキー割り当てと FunctionBar 表示の違いです。

## 実用安定版と高度機能α版での違い
利用モードによって、一部の高度機能の導線が表示されない場合があります。

| 利用モード | 方針 |
|---|---|
| 実用安定版（推奨） | 通常利用向け。基本機能を安定して使うためのモード |
| 高度機能α版 | 開発中の高度機能を含むモード |

たとえば、実用安定版（推奨）では次のような高度機能の導線が閉じられる場合があります。

- Workspace Snapshot
- MarkSlot 集合演算
- MarkSlot backup export / import
- 画像減色
- SVGコピー
- 高度な Command Palette 機能
- 高度な自動追従制御

詳しくは [PROFILES.md](PROFILES.md) を参照してください。

## 注意
キーバインドは今後の整理や公開前調整によって変更される可能性があります。

特に高度機能α版に含まれる機能は、仕様変更や導線変更が行われる場合があります。
