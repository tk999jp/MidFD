# 機能範囲・操作方式・配色

MidFDの初回／基本セットアップでは、次の5領域をまとめて確認できます。

1. 機能範囲
2. 操作方式
3. 表示
4. 配色
5. 外部アプリ

これらは互いに独立した設定です。機能範囲を変えても、操作方式や外部アプリのpathが自動的に失われることはありません。

## 表示

タブ表示は「縦型（推奨）」または「横型」から選べます。縦型では左側にcategory／tabを並べ、横型では上部にcategory／tabを表示します。初回セットアップでは縦型が選択され、基本セットアップを再表示すると現在の保存値が表示されます。

## 機能範囲

初回セットアップおよび設定画面では、利用目的に応じて「機能範囲（Feature Profile）」を選択できます。

### 基本機能のみ (MinimalCore)

ファイル管理の基本機能に絞って利用します。

- ファイル・フォルダの閲覧
- コピー、移動、削除、名前変更
- Mark
- 標準のキー操作
- 内蔵Viewer

高度な自動復元、外部受け渡し、高度機能ゲートは有効にしません。

### 便利機能まで使う（推奨 / PracticalStable）

「基本機能のみ」に加えて、実用的な便利機能を有効にします。

- 起動時に前回の状態を復元
- マウスジェスチャー
- Functionバーの詳細説明
- メディアファイルのEnter外部再生
- パスのパンくず表示


フォルダ変更の自動検知（FileSystemWatcher）は、現在すべての機能範囲で有効です。

通常はこの範囲から開始することを推奨します。PracticalStableではMidFD管理ゴミ箱はOFFで、OFF時の通常削除はWindows標準ごみ箱を使用します。

### すべての機能を使う (Full)

「便利機能まで使う」に加えて、すべての高度機能・拡張機能を解放します。

- **FeatureGate 高度機能**:
  - Workspace Snapshot（※個別の有効/無効設定でoverride可能）
  - MarkSlot Set Operations（スロット間の和集合・積集合・差集合等の集合演算）
  - MarkSlot Backup Transfer（スロット単位／全スロットのJSON入出力）
  - Image Quantization（画像量子化・パレット最適化）
  - SVG Clipboard（SVG画像データのクリップボード連携）
  - Command Palette Usage（Favorite／最近使ったコマンドの利用情報保存）
- **動作モード・外部受け渡し**:
  - MidFD管理ゴミ箱（Full presetを明示選択するとONになり、その後も個別checkboxで変更できます）
  - Drag ZIP（および内容一覧manifest同梱）
  - クリップボードのテキストをファイルとして貼り付け

Command Paletteの基本検索・実行は各機能範囲で利用でき、このgateはFavorite／最近使ったコマンドなどの利用情報保存に適用されます。

MidFD管理ゴミ箱、Drag ZIP、内容一覧manifest、クリップボードのテキスト貼り付けは「注意が必要な機能」として別グループに表示されます。

### 個別設定と個別Override

機能範囲プリセットを選ぶと各項目へ既定値が反映されますが、その後で個別のチェックボックスを自由に変更できます。

- **個別の動作設定**:
  - MidFD管理ゴミ箱、Drag ZIP、テキスト貼り付け等は、機能範囲とは独立した個別設定です。
- **Workspace Snapshot の個別Override**:
  - Workspace Snapshot は Full プロファイルで既定有効ですが、設定画面（「表示」タブ）またはセットアップ画面のチェックボックスから、プロファイルの既定値に関わらず**個別に有効/無効をOverride（優先指定）**できます。
- 現在値が3つの既知プリセットのどれにも一致しない場合は画面上に「個別設定」と表示されます。機能が無効化されたわけではなく、利用者が個別に組み合わせた状態です。

## 操作方式

### MidFD標準

現代的なshortcutと、MidFD標準のFunctionバー配置を使用します。

### FD／WinFD互換

Fキー、Shift+F、数字キーの一部をFD／WinFD寄りにします。

> [!NOTE]
> FD／WinFD互換はキー配置と表示上の互換を目的としたものです。オリジナルFDとの完全互換ではありません。また、利用できる機能範囲そのものを制限する設定ではありません。

詳しい割り当ては [KEYBINDINGS.md](KEYBINDINGS.md) を参照してください。

## 操作方式と配色の連動

配色で「既定色」を選んでいる場合だけ、操作方式に応じた既定配色を使用します。

| 配色の選択 | 動作 |
|---|---|
| 既定色 | MidFD標準ではStandard側既定／custom、FD／WinFD互換ではFD側既定／customを使用 |
| 明示した配色preset | 操作方式とは独立して、選択した配色を維持 |

「MidFD標準」「FD／WinFD互換」「Green」などは、明示配色presetとしても選択できます。たとえば、操作方式をFD／WinFD互換、配色をGreenにすると、キー操作はFD／WinFD互換のまま、配色はGreenのままです。

## 外部アプリ

セットアップ画面から次を指定できます。

- 7-Zip
- 動画tool folder
- 外部editor

### 7-Zip

未設定時は既知の場所から自動探索します。通常の圧縮画面は設定で次から選択できます。

- 自動
- 7-Zip標準Dialog
- MidFD簡易Dialog

「自動」は `7zG.exe` の標準Dialogを優先し、利用できない場合にMidFD簡易Dialogへfallbackします。

### 動画tool folder

同じfolder内の次の実行fileを役割別に使用します。

- `ffmpeg.exe`: 動画静止画preview
- `ffprobe.exe`: 動画情報・再生時間
- `ffplay.exe`: 動画・音声の外部再生

`ffplay.exe` が見つからない場合はWindowsの関連付けで開きます。静止画previewには `ffmpeg.exe` が必要です。

### 外部editor

任意のeditorを指定できます。未設定時でも内蔵Viewerなどの基本操作は利用できます。

## 初回起動時と設定画面からの再表示

### 初回起動時

- 「MidFD 初回セットアップ」として表示します。
- ［この設定で開始］で選択内容を保存して起動します。
- taskbar／Alt+Tabから確認できる独立した画面として表示します。

### 設定画面から再表示

- 「MidFD 基本セットアップ」として表示します。
- 設定画面の「起動・ログ」から開きます。
- ［設定画面へ反映］は外側の設定UIへ値を戻します。
- 永続保存は外側の設定画面で［適用］または［OK］を押した時点です。
- ［キャンセル］では外側UIと保存済み設定を変更しません。

## 後から個別に変更する場所

| 設定 | 主な場所 |
|---|---|
| 一覧表示・Viewer表示 | 表示 |
| 配色preset・custom色 | 配色 |
| Drag ZIP・MidFD管理ゴミ箱・clipboard貼り付け | 操作 |
| keybind・Functionバー・マウスジェスチャー | 入力割り当て |
| 7-Zip・動画tool・外部editor | 外部連携 |
| 前回状態復元・基本セットアップ再表示 | 起動・ログ |

初回セットアップは全設定を初期化する画面ではありません。主要な開始設定をまとめて見直すための画面です。
