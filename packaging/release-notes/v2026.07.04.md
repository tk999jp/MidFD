# MidFD v2026.07.04 - .NET 10移行とQuickAccess/メディア再生改善

この文書は次回公開候補の release note draft です。最終 tag と公開日は未確定です。

## Runtime guidance

- MidFD は **.NET 10.0 Desktop Runtime** を必要とする Framework-dependent 配布です。
- GitHub の `Code > Download ZIP` や `Source code (zip)` はソースコード用であり、実行用配布物ではありません。
- 通常利用する場合は GitHub Releases の `MidFD-win-x64.zip` を使用してください。
- 7-Zip / ffmpeg / ffprobe / ffplay は同梱していません。

## User-facing highlights

- QuickAccess のカテゴリ表示、カテゴリ並べ替え、数字ショートカット、検索導線を改善しました。
- メディアファイルの Enter 外部再生を整理し、動画は設定で切り替え、音声は設定に関係なく外部再生するようにしました。
- 設定 SQLite の source of truth を維持したまま、Portable / Installed profile の診断を整えました。
- Markdown / SQLite の read-only preview を追加しました。

## Known limitations

- Explorer 右ドラッグの完全な Shell 互換は未対応です。
- Managed Trash / Workspace / Session Restore の実移行は今回の公開範囲に含めていません。
- Installed profile は明示 opt-in であり、既定では有効化していません。
