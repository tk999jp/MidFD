# 利用モードとキー操作体系
MidFD には、利用できる機能範囲を切り替える「利用モード」と、キー操作の割り当てを切り替える「キー操作体系」があります。

この2つは別の設定です。

| 種類 | 役割 |
|---|---|
| 利用モード | 有効になる機能の範囲を切り替えます |
| キー操作体系 | 主にファンクションキーの割り当てを切り替えます |

## 利用モード
利用モードは、MidFDで有効になる機能範囲を切り替える設定です。

初回起動時に選択でき、後から設定画面でも変更できます。

## 実用安定版（推奨）
通常利用向けの安定モードです。

基本的なファイル操作と、日常利用で使いやすい機能を中心に有効化します。

主な有効機能:

- ファイル一覧表示
- タブ機能
- カテゴリ機能
- カーソル移動
- コピー / 移動 / 削除 / リネーム
- ソート
- フィルタ
- 基本プレビュー
- 画像プレビュー
- 設定読み書き
- QuickAccess
- アーカイブ操作 (7-Zip / Windows標準 fallback)
- MarkSlot 基本保存 / 復元
- 外部ツール基本実行
- Command Palette の基本機能

通常はこちらを推奨します。

## 高度機能α版
開発中または検証中の高度機能を含むモードです。

実用安定版の機能に加えて、より高度な機能や実験的な機能が有効になります。

含まれる可能性がある機能:

- Workspace Snapshot
- MarkSlot 集合演算
- MarkSlot backup export / import
- 画像減色などの画像処理系機能
- SVGコピーなどの高度な画像連携
- Command Palette の高度な履歴 / お気に入り系機能
- 高度な自動追従制御

高度機能α版には、不具合や仕様変更の可能性があります。

安定した利用を優先する場合は、実用安定版（推奨）を使用してください。

## 初回起動時の選択
MidFDを初めて起動したとき、利用モード選択ダイアログが表示されます。

選択肢:

- 実用安定版（推奨）
- 高度機能α版

選択した内容は `settings.json` に保存され、次回以降は保存されたモードで起動します。

キャンセルまたは右上の×で閉じた場合は、モードを保存せず、MidFDの起動を中止します。

## 設定画面での変更
利用モードは、設定画面から後で変更できます。

設定画面では、内部名ではなく次の表示名で表示されます。

| 表示名 | 内部値 |
|---|---|
| 実用安定版（推奨） | PracticalStable |
| 高度機能α版 | Full |

内部的には `PracticalStable` / `Full` という値を使用しますが、通常利用では表示名だけを意識すれば問題ありません。

## キー操作体系
キー操作体系は、主にファンクションキーの割り当てを切り替える設定です。

利用モードとは異なり、使える機能の範囲を切り替えるものではありません。

| 種類 | 内容 |
|---|---|
| 標準 | 現代的なショートカット中心の操作体系 |
| FD互換 | Fキー中心の操作体系 |

## 標準
標準は、現代的なショートカット操作を中心にした操作体系です。

Browser画面では、FD風のFunctionBarを表示せず、一覧領域を広く使います。

主な操作:

| 操作 | キー |
|---|---|
| 開く / 表示 | Enter |
| 関連付けで開く | Z |
| コマンド実行 | X |
| PowerShellを開く | H |
| コマンドプロンプトを開く | Shift+H |
| 再読込 | Ctrl+R |
| フィルタ | Ctrl+F |
| コマンドパレット | Ctrl+Shift+P |

## FD互換
FD互換は、Fキー中心の操作体系です。

> [!NOTE]
> 本書でいう「FD互換」は、主にキー操作体系や表示上の名称です。
> オリジナルの FD との完全互換を意味するものではありません。

FD風の操作感を重視し、Browser画面下部にFunctionBarを表示します。

主な違いは、ファンクションキー割り当てとFunctionBar表示です。

利用できる機能そのものを切り替えるものではありません。

## 利用モードとキー操作体系の組み合わせ
利用モードとキー操作体系は別々に設定できます。

たとえば、次のような組み合わせが可能です。

| 利用モード | キー操作体系 | 例 |
|---|---|---|
| 実用安定版（推奨） | 標準 | 通常利用向けの推奨構成 |
| 実用安定版（推奨） | FD互換 | 安定機能をFD風キーで使う構成 |
| 高度機能α版 | 標準 | 高度機能を標準キーで使う構成 |
| 高度機能α版 | FD互換 | 高度機能をFD風キーで使う構成 |

## 推奨設定
初めて使う場合は、次の組み合わせを推奨します。

| 項目 | 推奨 |
|---|---|
| 利用モード | 実用安定版（推奨） |
| キー操作体系 | 標準 |

FD系ファイラの操作に慣れている場合は、キー操作体系だけFD互換に変更できます。

## 注意
高度機能α版は、開発中の高度機能を含むため、不具合や仕様変更の可能性があります。

不具合報告は歓迎しますが、すべての報告や要望への対応を保証するものではありません。

安定した利用を優先する場合は、実用安定版（推奨）を使用してください。
