# キーバインド
MidFD は、キーボード操作を重視したファイルマネージャです。

このページでは、MidFD の主なキーバインドをまとめます。

## 操作体系について
MidFD には、キー操作体系として「標準」と「FD互換」があります。

| 種類 | 内容 |
|---|---|
| 標準 | 現代的なショートカット中心の操作体系 |
| FD互換 | Fキー中心の操作体系 |

> [!NOTE]
> 本書でいう「FD互換」は、主にキー操作体系や表示上の名称です。
> オリジナルの FD との完全互換を意味するものではありません。

この設定は、主にファンクションキー割り当てと FunctionBar 表示を切り替えるものです。

一部の追加導線は、設定画面の「操作」タブにある「高度な使い方 / 詳細オプション」の有効化設定で切り替えます。

## 最初に覚えるキー
まずは、次のキーを覚えると基本操作を始められます。

| 操作 | キー | 説明 |
|---|---|---|
| 開く / 表示 | Enter | 選択項目を開く、または内蔵ビューアで表示します |
| 関連付けで開く | Z | OS の関連付けでファイルを開きます |
| コマンド実行 | X | 選択項目や現在フォルダを使ってコマンドを実行します |
| PowerShell を開く | H | 現在フォルダで PowerShell を開きます |
| コマンドプロンプトを開く | Shift+H | 現在フォルダでコマンドプロンプトを開きます |
| 再読込 | Ctrl+R | 現在ディレクトリを再読込します |
| フィルタ | Ctrl+F | 一覧を絞り込みます |
| コマンドパレット | Ctrl+Shift+P | 機能や外部ツールを検索して実行します |

## Browserキーバインドカスタマイズ

設定画面の「操作 / 入力」から「キーバインド割り当て...」を開くと、Browser 画面の主要 Command に対するキー割り当てを変更できます。

- 操作プリセット（MidFD標準 / FD/WinFD互換）は、既定キーセットを決める正本です。
- ユーザーキーバインドは、その既定キーセットの一部を上書きする形で保存されます。
- Command ごとにキー変更、無効化、選択 Command の既定復帰、すべて既定に戻す操作ができます。
- 同じキーを複数 Command に割り当てると競合として検出され、保存は停止します。
- Help メニューの「コマンド一覧...」から、割り当て対象の Command 名と説明を確認できます。

> [!IMPORTANT]
> キーバインドカスタマイズの対象は Browser 画面です。
> ImageViewer、TextViewer、ArchiveContents、各種 Dialog のキー契約は対象外で、従来の専用キー操作が優先されます。

## Browserファンクションバー割り当て

設定画面の「操作 / 入力」から「ファンクションバー割り当て...」を開くことで、Browser 画面下部のファンクションバー表示・マウスクリック実行・および物理Fキー押下時の実行 Command をスロット（F1〜F12）ごとに変更できます。

- **補助導線としての役割**: ファンクションキーの割り当ては、主となる通常キーバインド体系（Enter / Z / X 等）とは独立した、画面上に見える「補助導線」として扱われます。
- **4面レイヤー対応**: 通常 / Shift / Ctrl / Alt の各F1〜F12タブを切り替えて、それぞれの面に個別に Command と表示名を割り当て可能です。
- **解決の一致**: 表示されているファンクションバーのボタンラベル、ボタンをクリックした際の実行判定、および対応する物理ファンクションキーの押下実行は、すべて同じスロット解決ロジックを共有するため、表示と実行の解決先が一致します。
- **プロファイル別管理**: 「MidFD標準」と「FD/WinFD互換」の各プロファイルごとに独立した割り当てテーブルを保持します。
- **FD/WinFD互換時の表示**: FD/WinFD互換プロファイルでは、一覧表示名が実際のファンクションバー描画に適合した英語短縮ラベル（`help / eXec / Copy / Delet / Renam` など）で表示され、説明欄に日本語詳細が表示されます。
- **制限**: 危険操作やカスタマイズ不可 Command は候補に表示されず、無効状態のコマンドはクリックしても実行されません。また、Browser 画面外（Viewer や Dialog 等）の専用Fキー契約には一切影響しません。

## Logdsk (ディレクトリ移動) 内での操作

| 操作 | キー | 説明 |

## マーク操作
MidFD では、対象ファイルをマークしてまとめて操作できます。

| 操作 | キー | 説明 |
|---|---|---|
| マーク切り替え | Space | 選択項目のマーク状態を切り替えます |
| マーク切り替え | Insert | 選択項目をマークし、次の項目へ移動します |
| ファイルのみ全選択 | Home | ファイルのみを全選択/全解除します |
| ディレクトリを含めて全選択 | End / Ctrl+A | ディレクトリを含めて全選択/全解除します |
| マウスマーク | Ctrl+左クリック | クリックした項目のマークON/OFFを切り替えます |
| マウスマーク | Shift+左クリック | アンカーからクリック位置まで範囲マークします |
| マウスマーク | Ctrl+Shift+左クリック | Shift+左クリックと同じく範囲マークします |
| マーク操作 | Tab | マーク関連操作に使います |

> [!NOTE]
> **Home / End / Ctrl+A の役割差について**:
> - **Home**: ファイルのみを対象とし、ディレクトリはマーク選択・解除の対象から除外します。
> - **End / Ctrl+A**: ディレクトリとファイルの両方を対象として、全選択・選択解除を一括して切り替えます。

MarkSlot を使うと、マーク状態を保存・復元できます。

## Archive Contents (ZIP内閲覧) 内での操作
ZIP アーカイブ内のファイル一覧（Archive Contents）ダイアログ内でのキー操作です。

| 操作 | キー | 説明 |
|---|---|---|
| 階層移動 / プレビュー | Enter | フォルダ/`..` は移動（階層移動）。テキストファイルは独立プレビュー表示（モデルレス）。非対応ファイルはBeep。 |
| マーク切り替え | Space | 選択項目のマーク状態（`*`）を切り替えます |
| マーク切り替え | Insert | 選択項目をマークし、次の項目へ移動します |
| 解凍 | U | マークがある場合はマークされたファイルを解凍。マークがない場合は現在選択中の対象を解凍し、実フォルダ選択時は配下の実ファイルを対象にします。`..` や空フォルダは安全に警告して停止し、ReadOnlyタブでは解凍不可です。 |
| 閉じる / キャンセル | Esc | ダイアログを閉じます。プレビューウィンドウが開いている場合はプレビューも自動で閉じます。 |

高度な使い方（詳細オプション）が有効になっている場合、MarkSlot 集合演算などの追加の高度なファイル選択操作を利用できます。

## 切り取り貼り付けの安全確認

- 複数項目（2件以上）の切り取り貼り付けは、実行前に確認ダイアログを表示します。
- Undo / Redo は、成功した切り取り貼り付け移動に対してセッション中のみ有効です。
- 本Phaseで追加した Undo / Redo 対象は、成功した切り取り貼り付け移動です。

## マウス操作 / ジェスチャー

| 操作 | 入力 | 説明 |
|---|---|---|
| Browser ジェスチャー | 右クリックドラッグ | Browser 画面でジェスチャー入力を開始します |

Browser のマウスジェスチャーは、設定画面から Command 割り当てを変更できます。

- 1方向4種（L / R / U / D）と2方向12種の合計16パターンに対応します。
- ジェスチャーごとに無効化、既定復帰、再起動後の復元ができます。
- 入力中はステータスバーに方向列と割り当て Command 名が表示され、一覧上に軌跡が表示されます。
- 危険操作やカスタマイズ不可 Command は候補に出ません。

## Viewer操作
内蔵ビューアでは、テキストや画像を表示できます。

| 操作 | キー | 説明 |
|---|---|---|
| 表示を閉じる | Esc | Viewerを閉じてBrowserへ戻ります |
| 全選択 | Ctrl+A | 通常テキストViewerで全文選択します |
| コピー | Ctrl+C | 選択内容をコピーします |

巨大ファイル向けの LargeText Viewer では、安全性のため通常テキストViewerと一部操作が異なる場合があります。

### 画像プレビュー画面でのメディア静止画プレビュー (VideoStill) 操作
既定では、動画ファイルに対して `Enter` または `V` で画像プレビュー画面を開きます。
設定で「メディアファイル Enter で外部再生する」を有効にしている場合、`Enter` は外部再生、`V` は静止画プレビューになります。

| 操作 | キー | 説明 |
|---|---|---|
| シーク（戻る/進む） | ← / → | 動画内の位置を前後に変更します（動画長に合わせて自動ステップ） |
| 大シーク（戻る/進む） | Shift + ← / Shift + → | 大きなステップで位置を変更します |
| 先頭へ戻る | Home | 動画の先頭（0秒）へ位置を戻します |
| 外部再生 | Ctrl+Enter | 現在プレビューしている位置から外部再生（ffplay等）を起動します |

### メディアファイル

| キー | 動作 |
|---|---|
| Enter | 動画静止画プレビューを開く |
| V | 動画静止画プレビューを開く |
| Ctrl+Enter | 外部プレイヤーで動画 / 音声ファイルを再生する |

設定で「メディアファイル Enter で外部再生する」を有効にした場合は、次の動作になります。

| キー | 動作 |
|---|---|
| Enter | 動画は外部プレイヤーで再生する / 音声は設定に関係なく外部プレイヤーで再生する |
| Ctrl+Enter | 動画静止画プレビューを開く |
| V | 動画静止画プレビューを開く |

ffplay が設定されていない場合でも、外部再生は Windows の関連付けで開きます。
動画静止画プレビューには ffmpeg.exe が必要です。

## 外部ツール Alt slot launcher
外部ツールに Alt+英数字 slot を割り当てると、キーボードから直接起動できます。

| 操作 | キー | 説明 |
|---|---|---|
| launcher表示 | Alt | 登録済みslotを一覧表示します |
| slot直接起動 | Alt+英数字 | 対応slotの外部ツールを起動します |
| 選択移動 | ↑ / ↓ / Home / End / PageUp / PageDown | launcher内の選択を移動します |

Alt+英数字の外部ツール slot と、Alt+F1〜F12 の Function layer は別の導線です。

高度な使い方（詳細オプション）の設定によって、表示される起動候補が切り替わることがあります。

## FD互換ファンクションキー
FD互換は、Fキー中心の操作体系です。

Browser画面下部に FunctionBar を表示し、Fキー操作を確認しやすくします。

| キー | 操作 |
|---|---|
| F1 | Help |
| F2 | Check / Execute |
| F3 | Copy |
| F4 | Edit |
| F5 | Rename |
| F6 | Sort |
| F7 | Filter |
| F8 | Tree |
| F9 | Logdisk |
| F10 | Unpack |
| F11 | Top |
| F12 | Bottom |

FD/WinFD互換操作プリセット（操作プリセットが「FD/WinFD互換」の場合）では、以下のWinFD風ショートカットも利用できます（「MidFD標準」操作プリセットの時は動作しません）。
これらのショートカットは、Browser画面（ファイル一覧表示）時のみ有効です。内蔵Viewer表示中は、それぞれのViewer専用のキーバインド（たとえば Viewer 中での Shift+F3 による「前検索」など）が優先されます。

Shift / Ctrl / Alt + F1〜F12 の追加レイヤーは、設定画面の Functionバー割り当てで確認・変更できます。FD互換の既定では `Shift+F6` が Shell 起動です。Alt layer の既定は標準側と同じく、`Alt+F1` 新規MidFD、`Alt+F2` Explorer、`Alt+F3` コントロールパネル、`Alt+F5` 設定を中心に使います。

FD互換は、利用できる機能そのものを切り替えるものではありません。
主にファンクションキー割り当てと FunctionBar 表示の違いです。

## Drag ZIP handoff
設定で「Shift/Ctrl+ドラッグでZIP化して渡す」を有効にすると、複数マーク対象を Shift または Ctrl を押しながらドラッグしたとき、`MidFD-drag-{hash}.zip` 1個として渡します。

- 既定はOFFです。OFF時は通常の複数FileDropです。
- 「ZIPに内容一覧manifestを同梱する」を有効にすると、ZIP内に `_midfd_drag_manifest.txt` を追加します。
- manifestには対象ファイル一覧、作成時刻、hash、基準ディレクトリ情報などが入ります。

## 高度な使い方と追加導線オプション
設定画面の「操作」にある「高度な使い方 / 詳細オプション」を有効にすることで、一部の高度な管理機能や追加導線を利用できるようになります。

標準状態（オフ）では、以下の追加導線や機能が非表示または無効になっています。

- Workspace Snapshot
- MarkSlot 集合演算
- MarkSlot backup export / import
- 画像減色
- SVGコピー
- 高度な Command Palette 機能
- 高度な自動追従制御

詳しくは [PROFILES.md](PROFILES.md) を参照してください。

## 注意
キーバインドは今後の整理や公開前調整によって変更される可能性があります。

拡張機能に含まれる導線は、標準機能とは別の用途として整理されています。
